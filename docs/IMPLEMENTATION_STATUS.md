# 팡팡농장 요청 전체 추적표

기준일: 2026-11-01. 이 문서는 현재 작업 상태의 기준이다. 과거 검토 기록은 PLAYABILITY_REVIEW.md에 보존한다.

## 사용자 결정과 적용 우선순위

- 기존 그림체·한국 시골 분위기·팡팡 세계관 유지. 정상 재배를 다시 만들지 않는다.
- 판매 → 튜토리얼 저장 → 시간 → 초반 안내 → 상점·식당 → 기존 제보/퀘스트 → 신규 기능 순서.
- 사용자 농장 초기화 금지. #test 저장 키는 farm-qa:로 분리하고 온라인 마을 업로드 금지.
- 2026-11-01: 사용자가 ‘보고서 추천안 사용’을 선택했다. 보상 수령 후 갱신, 불멍/도구 수치, 빈 밭만 삭제, 우편 1회 선물/수령 기한 없음, 접속 중 활동시간 기준 고사와 기존 식물 3게임일 유예를 기준으로 구현한다.
- 후속 지시가 앞선 UI 지시보다 우선한다. 하단 버튼의 글자는 표시하지 않고 접근성 이름만 유지한다. 상단 날짜·게임 시각만 남기고 아날로그 시계와 설정 내 중복 날짜·시간은 제거한다.
- ‘작업 중’은 구현/배포/화면 검사 일부가 남은 상태다. 테스트 모형 통과를 모바일 실기기 검증으로 표시하지 않는다.
