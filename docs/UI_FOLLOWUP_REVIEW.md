## 실제 검증
- 기존 동작 검사와 사운드 분리/이벤트/저장 복원/가격 버튼 검사 총 66개 통과.
- Chrome 실제 브라우저에서 PC 및 iframe 430px 모바일 크기로 설정·사운드·도구·우편함·게시판·식당을 확인.
- 게시판 모바일 측정: 패널 clientWidth=scrollWidth=301, 행 clientWidth=scrollWidth=293. 가로 넘침 없음. 본문 및 버튼 색은 갈색 실제 계산값 확인.
- 사운드 슬라이더는 이전 input.png의 장식 테두리를 덮어쓰고 border-image:none/높이12px 확인.
- 모바일 실기기 및 온라인 친구 농장 미검증. 기존 사용자 저장 데이터 초기화/이관 없음.
